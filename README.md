# PES-ALL-IN-ONE

An all-in-one web portal for gym protein food orders and 2nd-year MBBS book bookings with integrated WhatsApp checkout.

## Features

- **Food Ordering:** Select gym-focused high-protein foods (eggs, chicken, mutton, paneer, fish, soya chunks, fruit bowls) with custom serving sizes, item removal/deletion, cart clearing, and direct WhatsApp order generation.
- **MBBS Book Booking:** 2nd-year MBBS textbooks (KD Tripathi Pharmacology, Apurba Sastry Microbiology, Robbins Pathology) with bundle offer support (₹1200 each or ₹3000 for all 3) and direct WhatsApp booking.
- **Cart Management:** Interactive cart with individual item delete buttons, clear all option, and live counter updates.
- **Responsive Design:** Clean, modern, mobile-friendly layout.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla ES6)
